# Certificate Tool

[Скачать последнюю версию для Windows](https://github.com/Kreigen8/certificate-tool/releases/latest)
— файл `cer_tool_gui.exe`. Python и Microsoft Excel для запуска EXE и выгрузки не нужны.

## Обновление 2026.09.10.1

- Фоновая загрузка файлов, хранилищ Windows и контейнеров CSP. Отмена прекращает
  дальнейшее сканирование после завершения текущего обращения к провайдеру;
  частичный результат явно отмечается в строке состояния.
- Прогрессбар виден только во время операции. После завершения, отмены или ошибки
  он останавливается, сбрасывается и скрывается.
- Исправлены поиск сертификатов по открытому ключу, обработка отказа при чтении
  прав экспорта и освобождение контекстов сертификатов Windows. Имя контейнера
  больше не обязано содержать ФИО для связывания по открытому ключу.
- При снятой галочке «Показывать без сертификата» скрыты все строки без прочитанного
  сертификата, включая ошибки чтения. Галочка работает без повторного сканирования.
  Если сертификат прочитан, а ошибка касается отдельного свойства, строка видна.
- Добавлены учреждение, должность, оставшиеся дни и диагностические сообщения.
  Поиск учитывает эти реквизиты. Двойной щелчок открывает полные сведения о строке.
- Перед удалением показываются только выделенные в основной таблице контейнеры.
  «Удалить просроченные» выбирает только просроченные среди выделенных. Выбора
  области удаления в окне проверки нет. Без выделения удаление не выполняется.
- Убрана строка «Срок / В отчет / Открыть отчет». Кнопка «Отчет» выгружает показанные
  строки с сертификатами, с учетом поиска и сортировки. В Excel просроченные даты
  выделяются красным, даты окончания в ближайшие 30 дней — желтым.
- Свойства контейнера читаются через один контекст провайдера, одинаковые сертификаты
  разбираются один раз за сканирование, хранилище MY переиспользуется до конца загрузки.
- ZIP создается в фоне через временный файл с проверкой целостности. Пустые и
  недописанные архивы не считаются успешными. Во время удаления и архивации закрытие
  окна блокируется до окончания операции.

Кнопка «Журнал ошибок» открывает `logs/certificate_tool.log` рядом с EXE или исходниками.
При отсутствии прав записи используется `certificate_tool_logs` во временной папке Windows.
Журнал ротируется, содержит реквизиты контейнеров и диагностику и не отправляется автоматически.
Время и счетчики сканирования записываются в журнал; скорость зависит от CSP и носителя.

Сроки и статусы рассчитываются на момент загрузки. Проверка срока не проверяет отзыв
сертификата и доверие к цепочке. Совместимость с конкретными токенами требует проверки
в соответствующей среде. Операции удаления в тестах выполняются с имитацией API.

## Сборка текущей версии

Windows, Python 3.13 с Tcl/Tk:

```powershell
python -m pip install -r requirements-build.txt
.\build.ps1
```

Скрипт запускает тесты и собирает `release/cer_tool_gui.exe` только при их успешном
завершении. Для другого интерпретатора: `.\build.ps1 -Python 'C:\путь\к\python.exe'`.

Модули: `certificate_utils.py` — поля и сроки; `windows_crypto.py` — Windows/CSP;
`file_operations.py` — файлы и архивы; `scanning.py` — сканирование;
`enhanced_ui.py` — фоновые задачи и действия; `cer_tool_gui.py` — вкладки;
`csp_report.py` — XLSX; `diagnostics.py` — журнал.

Утилита для работы с сертификатами и контейнерами ЭЦП в Windows.

## Отчет по срокам ЭЦП (XLSX)

Во вкладке «Контейнеры ЭЦП (CSP)» нажмите «Показать контейнеры», затем «Отчет»
рядом со строкой поиска и выберите место сохранения файла `.xlsx`.

В отчет попадают все показанные строки с сертификатами, с учетом поиска и
сортировки таблицы. Выделение отдельных строк не ограничивает отчет.
Контейнеры без сертификатов пропускаются; просроченные сертификаты включаются.

Колонки: «№», «Наименование учреждения», «Должность», «ФИО», «Срок действия ЭЦП».
Учреждение и должность берутся из полей O и T сертификата. ФИО — из SN и G,
а при отсутствии полного набора этих полей — из CN. Отсутствующие сведения
остаются пустыми. Срок действия — дата окончания сертификата в формате
ДД.ММ.ГГГГ. Нумерация начинается с 1; заголовок закреплен, доступны фильтры Excel.
Для сохранения отчета установленный Microsoft Excel не требуется.

Программа позволяет:
- просматривать сертификаты в файловой системе;
- переименовывать файлы сертификатов по шаблону;
- удалять просроченные сертификаты;
- просматривать сертификаты в хранилищах Windows (реестр);
- работать с контейнерами ЭЦП (CryptoPro / ViPNet / Rutoken);
- находить просроченные контейнеры и удалять их;
- копировать служебные данные контейнеров (серийный номер, отпечаток и др.).

## 📂 Вкладки программы

### 1. Файлы сертификатов

Позволяет работать с файлами сертификатов в каталогах (`.cer`).

Возможности:
- выбор папки и поиск файлов сертификатов;
- фильтрация по CN (владелец сертификата);
- подсветка просроченных сертификатов красным цветом;
- переименование файлов по шаблону:
  - Фамилия Имя Отчество
  - Фамилия И.О.
  - без даты
  - с датой окончания срока действия
  - с датой начала и окончания;
- удаление всех просроченных файлов сертификатов.

---

### 2. Реестр (хранилища Windows)

Работа с системными хранилищами сертификатов Windows:

Поддерживаемые хранилища:
- CurrentUser
- LocalMachine (требует запуск от администратора)

Типы хранилищ:
- MY
- CA
- ROOT

Функции:
- просмотр сертификатов;
- поиск по CN;
- сортировка по столбцам;
- подсветка просроченных сертификатов;
- удаление всех просроченных сертификатов.

Если программа запущена не от имени администратора, чекбокс **LocalMachine** будет недоступен.

---

### 3. Контейнеры ЭЦП (CSP)

Работа с контейнерами закрытых ключей (CryptoPro, ViPNet, Rutoken).

Отображаемые данные:
- Scope (CurrentUser / LocalMachine);
- Провайдер CSP;
- Имя контейнера;
- Уникальное имя контейнера (PP_UNIQUE_CONTAINER);
- Владелец (CN);
- Дата начала действия сертификата;
- Дата окончания действия сертификата;
- Статус (Действующий / Срок действия истек / Без сертификата);
- Серийный номер сертификата;
- Отпечаток сертификата;
- Экспорт закрытого ключа (+ / -);
- Сертификат в контейнере (+ / -).

Дополнительно:
- поиск по CN, имени контейнера и уникальному имени;
- подсветка просроченных контейнеров красным;
- подсветка контейнеров без сертификата серым;
- чекбокс «Показывать контейнеры без сертификата».
